site que informa sobre navegadores que não suportam recursos modernos

Um site útil para verificar a compatibilidade de navegadores com recursos modernos é o Can I use. Este site fornece informações detalhadas sobre quais navegadores suportam diferentes tecnologias web, incluindo HTML5, CSS3, JavaScript e muito mais. Você pode pesquisar por um recurso específico e ver uma tabela de compatibilidade que mostra quais versões de navegadores suportam esse recurso.
