Prefixos no CSS

Prefixos CSS são usados para adicionar suporte a recursos que ainda não foram padronizados ou implementados em todos os navegadores. Eles permitem que desenvolvedores utilizem funcionalidades experimentais antes de serem amplamente suportadas.

Exemplos comuns incluem:

  • -webkit- (para navegadores baseados no WebKit, como Safari e Chrome)
  • -moz- (para navegadores baseados no Gecko, como Firefox)
  • -ms- (para versões antigas do Internet Explorer)
  • -o- (para versões antigas do Opera)
